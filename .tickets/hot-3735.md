# Watch command: monitor price drops

Add a 'hotella watch' command to monitor hotel prices and alert when a target price is reached.

Usage:
  hotella watch "Taipei" --checkin 2026-02-10 --checkout 2026-02-17 --target-price 100

Would poll periodically and notify when any hotel drops below the target price. Consider interval configuration, notification method (stdout, system notification), and persistent state for tracking price history.

## ⚠️ Design Decisions Needed

This ticket requires design work before implementation:
- Notification method: stdout only? System notifications (node-notifier)? Webhook/email?
- Persistent state: where to store price history? JSON file in ~/.cache/hotella? SQLite?
- Default poll interval and minimum safe interval (rate limiting concerns with Google)
- Output format while watching: clear-and-reprint? Append-only log? TUI with sparkline?
- Should it track a specific hotel or any hotel below target price?
- How to handle Google blocking repeated requests (rotating headers, backoff?)

Recommend: define the minimal viable UX first (e.g., stdout-only, in-memory history, single session), then iterate.

## Acceptance Criteria

- Watch command polls at configurable interval
- Alerts when price drops below target
- Shows price history/trend
- Graceful Ctrl-C handling
