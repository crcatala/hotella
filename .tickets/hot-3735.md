# Watch command: monitor price drops

Add a 'hotella watch' command to monitor hotel prices and alert when a target price is reached.

Usage:
  hotella watch "Taipei" --checkin 2026-02-10 --checkout 2026-02-17 --target-price 100

Would poll periodically and notify when any hotel drops below the target price. Consider interval configuration, notification method (stdout, system notification), and persistent state for tracking price history.

## Acceptance Criteria

- Watch command polls at configurable interval
- Alerts when price drops below target
- Shows price history/trend
- Graceful Ctrl-C handling
