# Dev tooling: test, lint, format, typecheck, verify scripts

Set up dev tooling scripts following the raindrop-cli pattern so coding agents can verify their work.

Tooling stack:
- Test runner: vitest (already configured)
- Linter: oxlint (with --type-aware)
- Formatter: prettier
- Typecheck: tsc --noEmit

Scripts pattern (agent-optimized):
- Silent-by-default scripts via scripts/check.sh wrapper (minimal output: ✓/✗)
- Verbose variants for humans (full output)
- scripts/run_silent.sh helper with run_silent() and run_silent_test() functions
- scripts/verify.ts runs all checks in parallel with summary
- scripts/test-unit.sh finds and runs unit tests (excluding *.live.test.ts)

Package.json scripts to add:
  test / test:verbose / test:live / test:live:verbose
  lint / lint:fix / lint:verbose
  format / format:verbose / format:check / format:check:verbose
  typecheck / typecheck:verbose
  verify / verify:verbose

Adapt from raindrop-cli pattern:
- Use pnpm + tsx instead of bun for script execution
- Use vitest instead of bun test
- Use npx for oxlint/prettier invocation
- verify.ts: replace Bun.spawn with child_process, drop tasuku dep (use simple output only)

Install devDependencies: oxlint, prettier

This ticket blocks all other work so agents have a way to verify their changes.

## Acceptance Criteria

- pnpm test runs unit tests silently, shows ✓/✗
- pnpm run lint runs oxlint silently
- pnpm run format:check runs prettier check silently
- pnpm run typecheck runs tsc --noEmit silently
- pnpm run verify runs all 4 checks in parallel with summary
- All :verbose variants show full output
- Existing source code passes all checks (may need minor fixes)
