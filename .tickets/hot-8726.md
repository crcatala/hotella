# Table output format (--table)

Add --table output format for tabular display of hotel results.

Implementation:
- Add --table flag to global options in src/cli/program.ts
- Add 'table' to OutputFormat type in src/cli/context.ts
- Implement table formatting in search command output

Table columns:
  Name (35 chars)  |  Price (8)  |  Rating (6)  |  Amenities (30+)

Format:
```
Name                               Price     Rating  Amenities
─────────────────────────────────  ────────  ──────  ──────────────────────────
MEANDER Taipei                     $32       4.6     Free Wi-Fi, Air conditioning
Grand Hyatt Taipei                 $271      4.4     Breakfast ($), Free Wi-Fi
```

Considerations:
- Truncate name/amenities to fit column width with ellipsis
- Right-align price column
- Handle null price (show 'N/A') and null rating (show '-')
- Auto-detect terminal width if possible, otherwise use fixed widths

Testing:
- Unit test for table formatting with various data
- Integration test: --table flag produces tabular output

## Acceptance Criteria

- --table flag produces aligned columnar output
- Columns: Name, Price, Rating, Amenities
- Handles null values gracefully
- Truncates long values with ellipsis
