# Multi-currency price parsing and --currency flag

Add --currency flag to the search command and enhance the parser to handle multiple currency formats.

CLI changes:
- Add --currency <code> option (default: USD) to search command
- Pass currency to fetcher as 'curr' query param (already in URL builder)
- Pass currency to parser for price extraction

Parser enhancements (src/lib/parser.ts):
- USD: $123 → already works
- EUR: €123 or 123 € 
- GBP: £123
- JPY: ¥12,345 or locale-specific
- TWD: NT$1,234 or TWD 1,234
- Handle comma vs period as thousands separator based on locale
- Fallback: extract any number that looks like a price from the card

Output changes:
- Plain text: show currency symbol appropriate to the selected currency
- JSON: currency field already exists on Hotel type

Testing:
- Unit tests for each currency pattern with sample text
- Live test: search Taipei with --currency TWD should show NT$ prices

## Acceptance Criteria

- --currency flag accepted with common codes (USD, EUR, GBP, JPY, TWD)
- Prices parsed correctly for each supported currency
- Plain output shows appropriate currency symbol
- JSON output reflects the requested currency
