# MCP server integration

Expose hotella functionality as an MCP (Model Context Protocol) server for use with AI agents.

This would allow AI assistants to search hotels programmatically. The library exports in src/index.ts already provide the building blocks (fetchHotelsHtml, parseHotelsHtml, sortHotels).

## Acceptance Criteria

- MCP server exposes hotel search as a tool
- AI agents can search hotels with structured input/output
- Works with Claude and other MCP-compatible clients
